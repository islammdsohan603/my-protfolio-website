# Personal Portfolio Website

A modern and responsive developer portfolio built with **Next.js 16**,
**Tailwind CSS**, and **Framer Motion**. This portfolio highlights projects,
skills, contact information, and professional details in a clean and interactive
UI.

---

## 🚀 Live Demo

Add your live website link here:
https://my-nextjs-protfolio-63osurko7-islammdsohan603s-projects.vercel.app/

---

## 📌 Features

- Responsive design for all devices
- Dynamic Projects section using JSON data
- Project Details page with dynamic routes
- Smooth animations using Framer Motion
- Modern UI with Tailwind CSS
- GitHub & Live Demo links for projects
- Professional portfolio layout
- Fast performance using Next.js App Router

---

## 🛠️ Technologies Used

### Frontend

- Next.js 16
- React.js
- Tailwind CSS
- Framer Motion
- React Icons

### Data Handling

- JSON Data Structure
- Dynamic Routing
